# Data sources

No data file is redistributed in this repository. Each open source is downloaded from its owner by the script listed.
Locations are set in `scripts/prc_config.py` (`docs/REPRODUCE.md` §0).

| source | what we use | how it is obtained | licence / terms |
|---|---|---|---|
| PRC Data Challenge 2026 (EUROCONTROL PRC) | airport movement records (`*_mvt`) and NM flight data (`*_flt`): the 2025 training months and the final ranking file (Jan, Feb, Jun, Jul 2026) with its submission template | challenge download, placed in `PRC_DATA` as `training_2025-MM-01_*.parquet`, `ranking.parquet`, `submitting.parquet` | challenge terms |
| adsb.lol `globe_history` (GitHub releases of `adsblol/globe_history_2025` / `_2026`) | per-day aircraft traces: ground and low-altitude points inside each airport box; 487 days = all of 2025, January, February, June and July 2026, and the edge days 2026-03-01 and 2026-05-31 (windows across the month edges) | `scripts/119_adsb_download.py` (`--preferred` takes the replica listed in `PREFERRED_RELEASES.txt`), `scripts/118_adsb_probe.py extract` | Open Database License (ODbL 1.0); allowed by the organisers |
| OPDI — Open Performance Data Initiative (https://www.opdi.aero/data) | flight list, flight events (stand / apron / taxiway / runway events) and measurements, 2025-01 … 2026-07 | `scripts/257_opdi_download.py`, `258_opdi_extract.py`, `259_opdi_flights.py`, `260_opdi_link.py` | as published by OPDI; use for the challenge confirmed with the organisers |
| X-Plane Scenery Gateway (https://gateway.x-plane.com) | airport layouts (`apt.dat`): stands (position, heading, size code), taxi network, runways — scenery ids LTFM 105504, EHAM 111943, EGLL 111341, LFPG 111022, EDDF 103368, LEMD 99851, LEBL 102255, EDDM 111124, LIRF 110482, LSZH 106102 | `scripts/fetch_external.py` (API `https://gateway.x-plane.com/apiv1/scenery/<id>`) | **GPL-2.0-or-later**: every Gateway scenery pack ships a `README.txt` stating that the packs are free software under the GNU GPL "either version 2 of the License, or (at your option) any later version", and the GPL v2 text as `COPYING`; compatible with this repository's GPLv3. Use for the challenge confirmed with the organisers |
| Iowa Environmental Mesonet ASOS/METAR archive (https://mesonet.agron.iastate.edu) | METAR of the ten airports, 2025-01 … 2026-07 | `scripts/fetch_external.py` | IEM public archive; attribution |
| OurAirports (https://ourairports.com/data/) | runway thresholds and headings, airport reference points | `scripts/fetch_external.py` | public domain |
| EUROCONTROL Aviation Intelligence Portal (https://ansperformance.eu/data/) | daily airport traffic and arrival ATFM delay; **monthly additional taxi-out time** (`Taxi-Out_Additional_Time.xlsx`) and additional ASMA time — inputs of the members (G6, `addl_taxi_out_min_month`, `asma_addl_min_month`; 2026 months without a published value take the same month of 2025, flagged `ec_monthly_is_prior`) | `scripts/fetch_external.py` → `scripts/20_ext_eurocontrol.py` | EUROCONTROL terms: attribution, non-commercial use |
| EUROCONTROL Aviation Intelligence Portal, **daily all pre-departure delay** (`all_pre_departure_delays_2025.csv`, `all_pre_departure_delays_2026.csv`, https://www.eurocontrol.int/performance/data/download/csv/all_pre_departure_delays_<year>.csv) | per airport and day: `DLY_ALL_PRE_2` (all pre-departure delay, minutes) and `FLT_DEP_IFR_2` (IFR departures). EUROCONTROL describes it as the daily total pre-departure delay by airport, all causes (https://ansperformance.eu/reference/dataset/all-pre-departure-delay/); both fields are supplied by the airport operator (`DLY_ALL_PRE_2`: minutes of pre-departure delay, all causes; `FLT_DEP_IFR_2`: IFR departures for which the airport operator submitted data). **The file is the daily sum of the airport-recorded off-block delays, so it is an aggregate of the off-block time the challenge masks in the ranking file**: 60 · `DLY_ALL_PRE_2` = Σ max(0, off-block − schedule) over the airport's departures with the recorded off-block on that UTC day (checked on 2025, `docs/METHOD.md` §11.2). It is used only by the post-steps after the final chain (`tools/last_day/`), never as a model feature. The organisers ruled on the monthly EUROCONTROL file above; they did not rule on this daily file. sha256 of the copies used: 2025 `d742eeb626e5f9f7e0c756e2ae3cf90078f4627e989a2e31b8ed21ba8f5510be`, 2026 `5952d20ef5f9c4245018dd6986064c5c4aa15d568a6c0c2dcdcbc73bf8a43fd2` (both downloaded 2026-10-13; the 2026 file grows as days are published) | `scripts/fetch_external.py` (section 5, checks the sha256) → `PRC_EXTERNAL/eurocontrol/` | EUROCONTROL terms of use (https://ansperformance.eu/about/disclaimer/): reuse with EUROCONTROL credited as the source, not for financial gain, no modification of the content without EUROCONTROL's written permission, no warranty |
| OpenAP (Python package) | aircraft dimensions for common types | `pip install openap` | LGPL-3.0 |
| holidays (Python package) | public holidays per airport country / region (G1 calendar features, `scripts/ext_calendar.py`) | `pip install holidays` (requirements.txt) | MIT |


Not used: OpenSky Network Trino historical data (not permitted by the organisers).

Revisions: the open sources can be revised after the date they were downloaded (adsb.lol replicas, OPDI releases,
EUROCONTROL workbooks, the Gateway's recommended scenery). The frozen artefacts (`docs/FROZEN_ARTEFACTS.md`) record the
derived tables that depend on an earlier download.
